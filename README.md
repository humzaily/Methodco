# MethodCo — Forever Foundation rebuild

A static, Cloudflare Pages-friendly implementation of the MethodCo Forever Foundation.

## Commands

```bash
npm test
npm run lint
npm run build:static
```

The production-ready output is written to `dist/`.

## Important truth boundary

This repository is a staging implementation created from the Forever Foundation and the currently published MethodCo site. It does **not** claim to be the source repository currently deployed at methodco.org. The connected GitHub repository was empty when this implementation was created.

Current Service prices and availability are preserved from the live site as observed on 2026-08-17. Financial figures for the five-pillar model are labeled as targets, not revenue or earnings promises.
